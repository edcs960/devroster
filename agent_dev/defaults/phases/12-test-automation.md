# 12 Test Automation Phase

## 목적

QA가 식별한 테스트 후보와 수용 기준을 자동화 테스트 코드로 구현하고 실행 결과를 남긴다.

## 적용 역할

- `AGENTS.md`
- `agent/test-automation.md`
- QA phase 결과

## 입력

- QA 산출물의 자동화 테스트 후보 목록
- 수용 기준
- 프론트/백엔드 저장소의 기존 테스트 컨벤션

## 수행 절차

1. QA 산출물에서 자동화 후보와 우선순위를 확인한다.
2. 기존 테스트 위치/패턴을 확인하고 같은 컨벤션으로 구현한다.
3. 테스트 코드와 테스트 설정 파일만 수정한다. 프로덕션 코드는 수정하지 않는다.
4. 테스트를 실행하고 통과/실패를 기록한다.
5. 프로덕션 결함으로 실패하면 issue로 해당 developer에게 라우팅한다.

## 산출물 형식

```md
# Test Automation 결과

## 1. 구현한 테스트
| 파일 | 대상 수용 기준 | 종류(unit/e2e) |
|---|---|---|

## 2. 실행 결과
- 명령:
- 통과/실패:

## 3. 자동화하지 못한 항목
- 항목과 사유

## 4. 발견한 프로덕션 결함
- 없음 또는 issue 라우팅 내역
```

마지막에 Harness Control JSON block을 포함한다.
