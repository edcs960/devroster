# 01 Planner Phase

## 목적

사용자 요청을 개발 가능한 요구사항으로 구체화하고, 기능 범위, 제외 범위, 우선순위, 수용 기준을 확정한다.

## 적용 역할

- `AGENTS.md`
- `agent/planner.md`
- 필요 시 `.agents/skills/dev-pipeline/SKILL.md`

## 입력

- 사용자 요청
- 실행 입력(snapshot)의 대상 작업 정의
- 관련 산출물: 사용자요구사항정의서, 유스케이스명세서, 사용자인터페이스설계서, 인터페이스설계서, 권한정의서, 정책정의서

## 수행 절차

1. 사용자의 최종 목적과 대상 사용자를 정리한다.
2. 포함 범위와 제외 범위를 나눈다.
3. 기능, 데이터, 권한, 상태, 검증, 이력, 비기능 요구사항을 도출한다.
4. MoSCoW 기준으로 우선순위를 부여한다.
5. Given-When-Then 형식의 수용 기준을 작성한다.
6. 불확실한 사항은 가정과 확인 필요 사항으로 분리한다.

## 완료 기준

- 요구사항이 테스트 가능한 수준으로 정리되어 있다.
- 범위와 제외 범위가 분리되어 있다.
- 다음 phase가 설계를 시작할 수 있다.
