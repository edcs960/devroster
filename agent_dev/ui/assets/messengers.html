외부 메신저 연결

슬랙 채널에 남긴 요청을 DevRoster가 주기적으로 확인해 처리하고, 결과를 같은 스레드에 답합니다. 허용한 사용자·봇의 메시지만 처리합니다.

1. 슬랙 앱 준비

  1. 슬랙 앱 관리에서 앱을 만들고 Bot Token Scopes에 channels:history(비공개 채널이면 groups:history)와 chat:write를 추가합니다.
  2. 워크스페이스에 설치한 뒤 Bot User OAuth Token(xoxb-로 시작)을 아래에 저장합니다.
  3. 요청을 받을 채널에서 /invite @앱이름으로 봇을 초대하고, 채널 정보의 채널 ID(C… 또는 G…)를 입력합니다.
  4. 요청을 보낼 계정의 사용자 ID(U…) 또는 피클 같은 앱의 봇 ID(B…)를 허용 목록에 넣습니다.

2. 봇 토큰

이 컴퓨터의 공통 인증 저장소에만 저장하며 화면·DB·내보내기에 다시 나오지 않습니다.

3. 채널과 허용 대상

머리말을 정하면 그 말로 시작하는 메시지만 명령으로 읽습니다. 비우면 채널의 모든 허용 메시지를 읽습니다.

허용할 명령

4. 리스너

터미널에서는 devroster messenger listen으로 실행합니다. 앱과 터미널 중 하나에서만 동작합니다.
