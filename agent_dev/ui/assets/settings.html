01

공통 기본값

새로 반영하는 프로젝트에 쓰는 기본 AI 도구·모델·실행 한도입니다. AI 도구별 로그인·모델·API 키는 AI 도구 메뉴에서 관리하며, 그 메뉴를 쓰는 프로젝트에는 여기의 AI 값이 쓰이지 않습니다. 소스 범위·검증 명령·실행 권한은 공통값으로 상속하지 않습니다.

실행 한도

비운 항목은 공통값을 지정하지 않습니다. 상한을 지정하면 프로젝트 지정값도 그 값을 넘을 수 없습니다.

공통 설정 없음

02

이 프로젝트에 반영

항목마다 공통값을 쓰거나 프로젝트 값으로 직접 지정합니다. ‘반영’을 누르면 새 프로젝트 프로필이 만들어지고, 기존 승인과 snapshot은 그대로입니다.

공통 기본값이 바뀌었습니다. 확인한 뒤 반영해주세요.

03

공통 MCP 연결

연결 정의는 한 번 등록하고 프로젝트마다 버전·자료 범위·도구를 골라 사용합니다. 인증 값은 이 화면에 표시하지 않습니다. 비활성화하면 모든 프로젝트의 사용이 즉시 막힙니다.

    04

    저장 위치

    관리 폴더와 프로젝트 설정 위치를 확인하고 옮깁니다. 이전은 사전 점검 → 복사 → 검증 → 전환 순서로 진행하며 원본을 지우지 않습니다.

    점검 결과

      실행하면 새 위치로 복사·검증한 뒤 마지막에 위치를 전환합니다. 원본은 그대로 남고, 전환 뒤에는 웹·CLI·앱을 다시 열어야 합니다. 관리 폴더를 옮기면 앱 전용 CLI 로그인을 다시 확인해주세요.
      중단된 이전 복구

      전환 뒤 새 위치에 쓰기가 있었다면 되돌리지 않습니다. 현재 DB를 보존하는 새 이전이 필요합니다.

      05

      작업 폴더 정리

      완료·취소된 작업의 작업 폴더(git worktree)와 작업 브랜치를 정리합니다. 작업이 기준 브랜치에 병합되었거나 GitHub에서 병합이 확인된 폴더만 지우고, 커밋하지 않은 변경이나 병합되지 않은 커밋이 있으면 이유와 함께 남깁니다.
