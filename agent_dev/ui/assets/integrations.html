어떤 도구를 선택할까요?

라이브러리 문서는 Context7, 화면 참고는 Stitch·Figma, 코드 구조는 Graphify·Serena를 선택하세요. Context Mode는 긴 자료에서 필요한 부분을 찾습니다. Ponytail은 MCP 서버가 아닌 선택형 개발 지침입니다.

연결 설정 → 인증·설치 준비 → 도구 목록 확인 → 실제 읽기 검사를 순서대로 진행하세요. 외부 자료는 참고 자료로 전달되며 원본 화면을 자동 수정하지 않습니다.
