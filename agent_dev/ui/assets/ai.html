    03

    API 키

    API 도구가 쓰는 키입니다. 값은 이 컴퓨터의 보호된 파일(0600)에만 저장하고 다시 표시하지 않습니다. 값 대신 env:환경변수이름을 입력하면 이름만 저장하고, 실행할 때 그 환경변수에서 읽습니다(셸 설정·launchctl setenv·비밀 관리 도구로 값을 넣어 주세요). 프로젝트 환경변수에 같은 이름의 키가 있으면 그 프로젝트는 자기 키를 씁니다.
